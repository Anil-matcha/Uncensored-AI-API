# Contributing

Thanks for helping keep this API guide accurate.

## Before opening a pull request

- Confirm model IDs, fields, image support, and prices against the current [Muapi catalog](https://muapi.ai/abliterated-llm-api).
- Mark price tables with the date they were checked. Do not present a snapshot as a guaranteed or permanent rate.
- Keep secrets, real API keys, private prompts, and private image URLs out of commits and issue reports.
- Use safe, ordinary prompts in examples. Do not publish benchmark claims unless the exact model, settings, test date, method, and results are included.
- Keep examples runnable with the dependencies listed in their file headers or this README.

## Pull request checklist

- [ ] Changed claims match the current public schema or catalog.
- [ ] Examples do not contain credentials.
- [ ] Links use canonical `https://muapi.ai` URLs.
- [ ] Documentation distinguishes model behavior from API behavior.
- [ ] Any price snapshot includes its review date.
