# Security Policy

Please do not open a public issue containing API keys, access tokens, private prompts, account information, or sensitive image URLs.

For an account or API-key issue, use [Muapi support](https://muapi.ai/support). For a vulnerability in this repository's examples or documentation, report it privately through GitHub's repository security reporting feature when available.

Rotate any credential that may have been exposed. This repository never needs a real API key committed to source control.
